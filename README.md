# JPA ID Generator

A Spring Boot project demonstrating different **JPA ID generation strategies** for entity primary keys.

## 🚀 Technologies

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- SQL

## 📌 What This Project Covers

- `@GeneratedValue`
- ID generation strategies
- `GenerationType.IDENTITY`
- `GenerationType.SEQUENCE`
- `@SequenceGenerator`
- JPA entity primary key generation

## 🎯 Purpose

This project was created to understand how **JPA generates and manages entity IDs** when saving records to a database.
